# 验证结果

## 已通过

- `npm test`：19 项。包含点击推进与等待不推进、所有资源点掉落守恒、采集进度保存、旧计时存档迁移、九宫格原料数量、工具保留，以及科技可达性、队列、电力、离线和存档恢复。
- `npm run test:ui`：页面导航、点击采集、飘字与实际库存、配方书、九宫格、缺料禁用、放入后合成、实际制作燧石镐、机器建造和配置；1040 px 窗口包含工作台无横向溢出，没有页面脚本异常。
- `npm run test:desktop`：Electron 真实窗口中点击采集、掉落、工作台合成、读取参考资料、任务对话框和画面截图。
- `node scripts/electron-smoke.mjs --packaged`：直接运行打包后的应用 exe，通过相同检查。
- Forge 导出器 Java 8 目标字节码编译及 jar 打包通过。
- Windows x64 NSIS 安装包构建通过。
