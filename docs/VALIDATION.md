# 验证结果 · v0.1.7

验证日期：2026-11-05。本次按用户“进行测试后进行打包发布”的明确要求执行；日常修改和后续打包仍默认不自动测试。

## 源码与界面

- `npm test`：55 项通过，无失败。含 13 项新增能源测试，覆盖手动装煤／升温、水汽余数、直连／储罐耗汽、四类燃料转换守恒、共享安培、电池安装与容量、过压拒绝、付费升级、聚变启动与暂停、同一步流体读写、旧存档能源迁移、离线一致性、戴森供能。
- `npm run test:ui`：浏览器流程通过，覆盖 NEI 配方／用途、连续点击随机掉落、九宫格、手工队列、桶装流体、锅炉余汽与储罐转移、建造和 1040px 窗口。
- `npm run test:ui:energy`：19 项窗口／交互检查通过，覆盖装入电池后充电、从电池箱取电、切换直连、锅炉装煤、指定蒸汽输出罐、直连蒸汽及连接持久化。
- `npm run test:ui:layout`：79 项通过。窗口为 1040×680、1280×720、1440×960、1920×1080、2048×1090、2560×1440，并覆盖同一页面实时缩放、工厂默认分类与展开组、仓库、容器卡片及采集台数。
- `npm run test:ui:tiers`：99 项通过，覆盖 15 级数据与主题同步、键盘操作、MAX、减弱动态效果，以及 390×680 至 1920×1080 的外观页面。
- `npm run test:ui:performance`：固定外观切页根节点写入为 0；60 台暂停设备的工厂在连续刷新期间可见内容写入为 0；进度、强制停止与换配方仍正常。
- `npm run test:desktop`：使用独立临时资料完成 Electron 启动、版本、图标、采集、工作台、仓库、工厂、强制停止和电压外观检查。
- 215 个物品／流体的 SVG 图标均存在；数据为 184 条配方、30 类机器。JavaScript 语法及 Git 差异空白检查通过。
