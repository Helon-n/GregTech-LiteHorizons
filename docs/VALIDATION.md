# 验证结果

## 已通过

- `npm test`：28 项。新增桶的实际合成启用、无容器不存流体、兼容范围、单流体／容量、转移守恒、多产物容量规划、机器满罐暂停、并行产线保留已完成批次、离线容量、schema 2 迁移及非法容器存档校验、物品配方与工具用途查询。保留点击采集、科技可达性、九宫格数量、队列、电力和存档恢复检查。
- `npm run test:ui`：物品名列表、R／U 查询、点击原料跳转、多工艺翻页、工作台合成、木桶启用与装水、仓库无散装水、储罐满时锅炉暂停及转移后恢复。1040 px 包含容器和配方界面无横向溢出，没有页面脚本异常。
- `npm run test:desktop`：Electron 真实窗口中的物品配方／用途查询、采集、木桶合成启用、装水、仓库无散装流体、本地资料与任务对话框。
- `node scripts/electron-smoke.mjs --packaged`：直接运行打包后的应用 exe，通过相同检查。
- `node scripts/electron-smoke.mjs --portable`：从免安装单文件 EXE 自解压启动，通过相同交互检查。
- Forge 导出器 Java 8 目标字节码编译及 jar 打包通过。
- Windows x64 NSIS 安装包构建通过。

## 尚未验证

- 没有逐条对照原版 NEI；全流程原版准确性不属于已通过项目。
- 没有完成整条星门产线的人工长期游玩。可达性检查证明材料路线无阶段死锁，不证明全链平衡合理。
- Forge 导出器没有在用户实际 GTNH 加载过程中执行。
- 已测试打包应用 exe，但未向系统安装 NSIS 包；没有改变系统安装记录。
- 不同电脑、不同 Windows 版本和分辨率尚未广泛测试。

UI 检查使用独立临时浏览器／Electron 用户目录；测试资料明确是隔离的合成资料，不写入用户 Minecraft 或正式应用存档。
