# 配方树与制作计划 · v0.1.19

在「配方与工作台」选择目标配方，进入「配方树」。目标按 1–999 批计算，不把已有目标产物抵扣本次制作数量。材料依赖默认展开，可折叠、分页、点击物品查看配方；「底层缺料」汇总需要采集或自行提供的材料，「制作顺序」按依赖先后显示工序。

多种获取方式使用图标卡片切换。默认把可采集资源视为底层原料，其余优先考虑收藏配方及已有加工机器，再选择可用路线；可手动指定手工、机器或采集路线。共享库存账本扣除已用原料，并复用余料、副产物和不消耗的工具，避免各分支重复占用库存。全部章节的配方均可参与依赖计算，遇到循环、条件不满足或过大的依赖树会显示缺料／错误，不生成免费材料。预览是库存快照，点击「按当前库存重算」更新。预览在模块 Worker 中计算，等待时界面可继续操作；切换目标、批数或路线会取消旧计算，分页、折叠和模拟时钟不会重算依赖树。

「安排制作」会以点击时的库存重新计算，并保存一份制作计划。每次只推进当前工序：手工任务逐批加入原有队列；普通加工工序交给兼容电压的空闲实体机器，按计划批数完成后清空配方并停机；目标为机器建造时调用已有建造规则。派工优先选择已有机内能源或已指定供能来源的机器。不会接管已有任务，设备组中的实体机器仍使用组配置的供能和流体端口。

缺料、缺工具、缺空闲机器、供能不足或流体容器空间不足都会等待，不跳过原有支付、能源或流体规则。计划按预先计算的工序执行，不持续重算整棵树；计划执行期间把材料移作他用，可能需要重新补齐。不会自动采矿、自动建设下级加工机器、布置容器或更改供能／流体输出连接；锅炉、发电机等持续产能设备需在工厂配置，不当作普通合成批次。

章节仅作主线参考；制造仍保留实际材料、工具、研究数据、电压、算力、环境与实体容器条件。研究前置列入备料树，运行时由设备再次校验。培养箱、束流源/合成与其他概率/持续系统须在工厂配置，计划不会按期望产量自动补齐或接管持续连接。

支持暂停、继续及取消。暂停／取消停止安排新批次，已投料的当前批次继续完成；没有投料的机器任务立即释放。强制停止计划机器、手动更换其配方、取消计划的手工任务或拆除计划机器，会暂停后续计划，防止任务立刻被重新派回。手工取消沿用原队列退料规则，机器强制停止沿用已有不退料规则。取消后的在制批次结束前不能创建另一份计划。

计划、完成批数、暂停状态和在制任务标记随世界保存、备份及导入导出，继续使用 schema 4；旧存档默认没有计划。重开游戏不推进关闭期间的计划或生产。读取时验证配方、批数及在制归属。

实现位于 `src/core/production-plan.js`、`src/recipe-tree.js`、`src/recipe-tree.css`，与现有模拟、真实库存和配方数据集成。参考原网页的递归备料与合成计划交互，实现代码为本项目新增；未照搬网站运行脚本、资源包或其不同版本的配方数据。深度／节点／批数上限用于限制复杂树的计算量；依赖计算只发生在目标、批数、路线或手动刷新变化时，模拟时钟仅刷新局部进度。

v0.1.19 将来源、工艺与兼容设备索引缓存到目录对象上，采集点访问权限仍按玩家当前工具和地区实时检查。预览超过深度／节点上限时保留已知节点并显示原因，禁止安排不完整计划；培养箱、连续换热、束流等不能普通按批安排的配方显示本配方直接材料及工厂入口，不能把参考需求当作完整计划。没有制造配方的资源直接列出采集地点、缺少的工具／研究／地区入口，并可导航到具体地点。小窗口压紧标题、摘要与说明间距，维持格子和文字尺寸，由分页决定可见材料数量。
