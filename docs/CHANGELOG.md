# 版本记录

## v0.1.7

- 重构能源：锅炉额定 120 mB/s、1:160 水汽比、升温／冷却、机内水汽缓冲和满罐排汽；按实例配置手动装煤。蒸汽机器改为运行时持续耗汽，青铜工时翻倍。
- 每台用能设备选择直连产能机器或指定储罐／电池箱；发电机、消费者各有内部缓冲，共享电源输出上限，限制电压并采用普通超频，不再使用随章节免费的全局电力缓存。
- 电池箱必须装入同级电池后充放电，电池数决定安培；加入 LV–UXV 电池与付材料的机组升级。旧全局 EU 保留为待转存额度，只能向有电池的电池箱转存。
- 校准蒸汽、柴油、氢气、氦等离子体发电的热值、转换比与机组效率；新增燃气轮机、同位素离心，修正水电解能耗与氘氚聚变配方／启动储能。戴森不再用氢气任意发电，改按实例模块功率、极寒之凛冰周期和损耗运行。
- 工厂供能页显示连接、缓冲、耗汽／耗电、发电率、电池和升级操作；不同电压或连接的设备分别合并。新增原始 GTNH 能源图标的 SVG 路径和来源记录。
- 存档升为 schema 4，迁移原有批次和已付但未用完的能源。参数出处及未复刻范围见 `docs/ENERGY.md`。按本次明确要求执行测试与 Windows 双 EXE 打包；详细结果见 `VALIDATION.md`。
- 修复旧发电批次迁移时因工时改变导致剩余燃料计算偏大；新增能源守恒、电池、安培、聚变启动和存档迁移回归测试。
- 修复小窗口外观预览按钮越界、总览生产速览导致下方内容越界及大窗口展开设备组被压窄；内容通过测量、页签和稳定网格访问。
- 统一布局规则：格子尺寸稳定、面板随内容定高、窗口决定展示数量。资源、星际远征、工厂及组内设备、仓库、桶与储罐、图鉴、科技和选择卡片共用尺寸表与分页计算；尾页保留正常列宽。
- 移除设置、日志、采集、设备和储罐的剩余高度填充；投入／产物、进度与操作紧凑排列，面板外保留合理空白，文字与真实内容可自然增高。
- 分页根据实际名称、选择按钮和电压外观后的高度收紧，并为分页与下方操作保留空间；窗口改变时保留原先首项所在位置。相同布局复用容量，不在游戏定时刷新中测量布局。
- 工作台槽位与网格共用尺寸变量，修复大窗口机器配方原料槽重叠，投入、箭头与产物统一对齐。图鉴格子与配方区不再随窗口拉伸，容器目录也支持分页。
- 总览按内容排布，窗口宽高足够时显示真实仓库、生产状态与最近日志；工作台同时显示每批原料库存、工厂派工与分页队列，小窗口保留页签访问。
- 工厂删除“全部设备”分类，仅按具体机型查看；默认选中首个已有设备的分类，当前分类设备全部拆除后自动切换到可用分类。
- 发布流程默认只打包，不自动执行测试或启动应用；保留双 EXE、旧包清理、校验和与 Git 版本归档。

## v0.1.6

- 按窗口实际可用宽高计算资源、机器和储罐的行列与分页容量，其他页面随窗口拉伸；扩大窗口时增加可见内容，减少底部空白。
- 工厂默认将有任务的设备放前面，同机型同配方自动合并；机器分类改为带图标的直接操作按钮。
- 自动采集台数改为减／加／全部按钮；工作台物品使用图标网格，机器配方、派工设备、限定流体和转移容器使用卡片选择。
- 优化界面切换：相同电压外观不重复写入全局样式，队列与容器首次显示不再重复生成。
- 实时刷新仅更新变化的文字、状态和进度；机器只查询当前可见卡片，选择框只在新增时初始化，减少后台刷新对切页的影响。
- 保留原有游戏计时、生产、存档与电压外观；同步提供免安装单文件与安装版。

- 总览分主线／仓库与生产／日志，工作台分配方／派工／队列，资源分手动／自动采集；容器分放置列表与容器目录。
