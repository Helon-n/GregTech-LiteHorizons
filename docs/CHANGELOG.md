# 版本记录

## v0.1.2

- 每个版本同时输出可直接运行的免安装单文件 EXE 与安装版 EXE，两者均纳入发布验证。
- 流体从物品仓库移至独立桶与储罐；加入四种可合成容器、单种流体限制、容量、预留类型、转移与收起空容器。
- 机器产物容器不足时暂停，保留已扣料批次；在线、离线和并行机器均遵循相同规则。
- 老存档散装流体自动装入迁移储罐，保留数量和累计获得记录。
- 配方入口显示物品名，支持 NEI 风格配方／用途查询、R／U、右键用途、点击原料跳转和多工艺切换。
