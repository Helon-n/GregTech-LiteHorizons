# 版本记录

## v0.1.6

- 按窗口实际可用宽高计算资源、机器和储罐的行列与分页容量，其他页面随窗口拉伸；扩大窗口时增加可见内容，减少底部空白。
- 工厂默认将有任务的设备放前面，同机型同配方自动合并；机器分类改为带图标的直接操作按钮。
- 自动采集台数改为减／加／全部按钮；工作台物品使用图标网格，机器配方、派工设备、限定流体和转移容器使用卡片选择。
- 优化界面切换：相同电压外观不重复写入全局样式，队列与容器首次显示不再重复生成。
- 实时刷新仅更新变化的文字、状态和进度；机器只查询当前可见卡片，选择框只在新增时初始化，减少后台刷新对切页的影响。
- 保留原有游戏计时、生产、存档与电压外观；同步提供免安装单文件与安装版。

## v0.1.5

- 接入 ULV 至 MAX 的 15 级电压外观，默认随科技阶段变化，支持独立固定外观；保留四阶段结构、材质纹理及 MAX 浅色例外。
- 设置增加可键盘操作的电压阶梯、真实基地预览和同步 STYLE DNA；按窗口高度切换页签、阶段和详情分页。
- 现有组件统一使用配色变量及电压／阶段／纹理属性，取消组件中的固定界面色值；字体使用本地资源。
- 固定窗口布局，取消页面、侧栏和弹窗滚动条；列表按窗口大小分页。
- 总览分主线／仓库与生产／日志，工作台分配方／派工／队列，资源分手动／自动采集；容器分放置列表与容器目录。
- 分类、配方、流体、转移目标和并行台数等选择框支持搜索和分页，不再打开可滚动的原生下拉列表。
- 工厂合并组内逐台设备增加分页，展开非首页分组也保持选中的配方组。
- 从原始 Minecraft 与模组 jar 重新提取图标，不读取额外材质包；界面图标转为不嵌入位图的 SVG 路径。

## v0.1.4

- 应用更名为 GregTech-LiteHorizons，窗口、界面、存档导出与发布文件名同步更新；保留原存档目录及应用身份。
- 长列表加入分页，工厂整理时有任务的机器优先；相同机型和配方可合并展示并展开逐台操作。
- 配方页可直接派工至兼容的空闲机器，手工配方可交给已建成的工作台运行。
- 材料、机器、元件和导航改用本地 GTNH 材质，应用图标同步更新，附素材来源与导入脚本。
- 桶与储罐并入物品仓库，通过物品／桶与储罐页签管理。
- 自动采集支持停止、恢复、选择同时工作的机器台数；自动 ×2 表示两台机器并行，每台周期不变，设置随存档保存。

## v0.1.3

- 删除原版资料页面、配方导入入口、开发用语与重复教程，仅保留主线目标和必要操作状态。
- 放大正文、按钮、物品与配方格文字，调整卡片和窄窗口布局。
- 生产工厂按机器类型分组，可筛选机型并查看台数。
- 新增强制停止：取消当前批次、清空配方并停机，允许立即切换生产物品；已投入原料和电力不返还。
- 采集固体按范围随机掉落，手动、自动与离线采集共用规则；界面显示范围，随机状态随存档保存。流体体积和机器配方产出保持固定。
- 兼容旧存档，保留已有物品、容器、设备与主线进度。

## v0.1.2

- 每个版本同时输出可直接运行的免安装单文件 EXE 与安装版 EXE，两者均纳入发布验证。
- 流体从物品仓库移至独立桶与储罐；加入四种可合成容器、单种流体限制、容量、预留类型、转移与收起空容器。
- 机器产物容器不足时暂停，保留已扣料批次；在线、离线和并行机器均遵循相同规则。
- 老存档散装流体自动装入迁移储罐，保留数量和累计获得记录。
- 配方入口显示物品名，支持 NEI 风格配方／用途查询、R／U、右键用途、点击原料跳转和多工艺切换。
