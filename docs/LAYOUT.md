# 界面布局约定

格子尺寸稳定，面板随内容定高，窗口决定展示数量。空白留在面板外部；窗口变大时增加可见行列或显示关联面板，不放大单张卡片，也不拉开配方与操作按钮。

## 共用尺寸

尺寸数据集中在 `src/layout.js`。`planGrid` 根据页面实际可用宽高、顶部工具栏和分页空间计算容量；`gridStyle` 将轨道宽度、间距等传给 CSS。所有分页保持正常列数，尾页不按剩余条目数重新分配列宽。

| 内容 | 常规宽度 | 高度规则 |
| --- | --- | --- |
| 资源、星际资源、桶与储罐 | 360px | 随真实内容 |
| 工厂设备、合并组、组内设备 | 370px | 随真实内容 |
| 仓库物品 | 260px | 至少 82px，允许长名称换行 |
| 配方图鉴 | 112px | 至少 128px，允许长名称换行 |
| 科技章节 | 370px | 随真实内容 |
| 容器建造目录 | 520px | 随真实内容 |
| 选择卡片 | 205px | 普通至少 140px，机器配方至少 220px |

窗口宽度不足一列时，卡片可缩到可用宽度。工作台投入、九宫格和产物共用槽位尺寸变量，箭头固定居中；放大窗口不放大槽位。

## 高度与分页

面板移除 `flex:1`、百分比满高和 `1fr` 均分行高等填充规则。设置、主线、日志、机器配方、储罐读数及采集操作按内容连续排布；总览限制整体宽度，宽高足够时才同时展示仓库、生产或日志。

尺寸表中的 `rowHeight` 是初始分页预算。生成真实名称、选择按钮和电压外观之后，`fitPageLimits` 检查自然行高，并为分页及下方按钮保留空间；装不下时减少整行或条目，重新分页。缩放窗口时按原先首项定位新的页码。相同布局上下文保留收紧后的容量，避免每次翻页重复尝试更大的容量。

高度读取只在页面重建时执行，不加入游戏定时刷新。配方、目标、队列及长列表保持分页访问；不通过截掉溢出内容来完成适配。电压外观页沿用自身的内容测量、阶段分页、预览与 DNA 页签。

总览生产速览也根据自然行高收紧条目，为下方仓库与日志留出空间。展开设备组使用可用宽度容纳稳定卡片；外观预览在小窗口拆为电量／生产页签，不截断底部按钮。
